# Sedentarismo — Entenda os Riscos e Viva Melhor

Site sobre sedentarismo desenvolvido como projeto da disciplina de Desenvolvimento Web.

## 📌 Sobre o projeto

Página informativa sobre os riscos do sedentarismo e como promover hábitos saudáveis,
com uma calculadora interativa que verifica se o usuário atinge os 150 minutos semanais
de atividade física recomendados.

- **Tema:** Sedentarismo
- **Fonte do conteúdo:** [Hospital Alemão Oswaldo Cruz](https://www.hospitaloswaldocruz.org.br/centro-especializado/obesidade-e-diabetes/sedentarismo-entenda-os-riscos-e-como-promover-habitos-saudaveis-para-melhorar-a-qualidade-de-vida/)
- **Estilo visual:** Estética vintage e minimalista
